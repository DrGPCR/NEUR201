## Before you start

**1. Save your own copy.** When a notebook opens, click **File → Save a copy in Drive** straight
away, or your work won't be saved.

**2. Run every cell, in order, from the top** (**Shift + Enter**).

**3. Watch for these:**

| | What to do |
|---|---|
| **Ordinary cells** | Just run them. |
| **⚙️ Try it** | Change the highlighted value, re-run, see what changes. |
| **💬 Discussion** | Double-click and type your answer. |

**4. A note on W5 L2 and the Data Analysis assignment:** the first cell installs the NEURON
simulator, which takes a minute or two. That's normal — wait for it to finish before running
anything else. If the Colab runtime restarts, run that cell again.

## Submitting your work

1. Answer every **💬 Discussion** cell.
2. **Runtime → Run all** so every graph and answer is visible.
3. **File → Print → Save as PDF**, then upload the PDF to Canvas.
